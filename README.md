# Vicuna (فيكونا) — موقع vicuna-eg.com

> الملف ده هو "دليل التسليم" الكامل للموقع: إيه اللي اتبنى، فين كل حاجة، إزاي تعدّل بنفسك، وإزاي أي مساعد ذكاء اصطناعي تاني (ChatGPT / Codex / Cursor …) يكمّل الشغل بنفس الطريقة.
> آخر تحديث: 5 أكتوبر 2026.

## 1) الموقع باختصار

| البند | القيمة |
|---|---|

| الكود | GitHub: `5aledelaraby/belts` (فرع `main`) |

## 2) إيه اللي موجود على الموقع (من أول البناء لحد النهارده)

### الصفحة الرئيسية `/` (بالترتيب من فوق لتحت)
1. **شريط علوي متحرك** فيه العروض (الخصم + التوصيل).
2. **الهيدر**: اللوجو، اللغة (عربي/English)، أيقونة السلة اللي بتلمع.
3. **الهيرو**: "Vicuna" + جملة *The wrap belt that accentuates your waist* + كبسولة "توصيل لكل مصر" في النص + 6 أحزمة طايرة بتتحرك + توهج خفيف.
4. **المميزات** بأيقونات مرسومة (طيارة للتوصيل، فلوس للدفع عند الاستلام، استرجاع، مقاس، هدية…).
5. **شريط العرض**: الحزام التاني −25%، التالت −35%، وبيتكرر كل 3 أحزمة، والخصم على الأرخص.
6. **المتجر (`#shop`)**: كل الأحزمة + فلاتر بالتصميم واللون + "نظرة سريعة" + إضافة للسلة.
7. **تسوقي بالتصميم**: كروت للتصميمات الستة.
8. **إزاي تربطيه**: كارت صغير وبسيط.
9. **شغل إيدينا**: كولاج صورتك مع الأحزمة + صورة الحزام الكحلي لوحده + فيديو قص الليزر.
10. **على الطبيعة**: صور الأحزمة ملبوسة (onbody 1–7).
11. **التفصيل بالجلد الطبيعي** (خلفية كونياك): فيديو تفاصيل الجلد + 3 خطوات (تبعتيلنا ← موظفة تيجي تاخد المقاس وتوريكي الخامات وتتفقوا على السعر ← نفصّله ونبعتهولك). القاهرة والجيزة بس.
12. **آراء العملاء**: 28 سكرين شوت حقيقية من فيسبوك (بإذن أصحابها) + تقييمات حنان ودنيا.
13. **الأسئلة الشائعة**: مقفولة لحد ما العميلة تدوس.
14. **الفوتر الأسود**: اللينكات، المقالات، بيانات الشركة والسجل التجاري، و *Designed by* + توقيعك بخط إيدك + قلب أحمر بينبض.

### حاجات بتظهر وقت الاستخدام
- **السلة الجانبية**: الإجمالي + سطر الخصم + زرار كتم/تشغيل الأصوات + إرسال الطلب على واتساب.
- **كارت تشجيع** بيظهر مرة واحدة بعد أول إضافة للسلة ("ضيفي التاني بخصم 25%").
- **أصوات كليك خفيفة** (WebAudio) ومؤثرات (ripple، ظهور بالسكرول).
- **رسالة شكر + كونفيتي** بعد إرسال الطلب.
- **كارت هدية عيد الميلاد** بيظهر بعد السكرول (مش في المقالات ولا صفحات السياسات).
- **فقاعة مساعدة واتساب** مرة واحدة بعد 30 ثانية من تفاعل حقيقي.
- **زرار سهم أبيض** يرجّعك لفوق.

## 4) إزاي تشوف الأكواد بنفسك

**أسهل طريقة (من غير أي برامج):**
1. افتح https://github.com/5aledelaraby/belts
2. ادخل على فولدر `src` وشوف الملفات.
3. تعديل بسيط (رقم/كلمة): افتح الملف ← أيقونة القلم ✏️ ← عدّل ← **Commit changes**.
   ⚠️ تعديل `src/` من GitHub **مش هيظهر على الموقع** غير لما حد يعمل build (الخطوة 5). عشان كده للتعديلات الكتير استخدم الطريقة اللي تحت.

**على الكمبيوتر (الطريقة الكاملة):**
1. نزّل وسطّب: [Node.js](https://nodejs.org) (نسخة 22 أو أحدث) و [Git](https://git-scm.com) و [VS Code](https://code.visualstudio.com).
2. افتح Terminal واكتب:
   ```bash
   git clone https://github.com/5aledelaraby/belts.git
   cd belts
   npm install
   ```
3. نزّل **Tailwind CSS v4 standalone** من https://github.com/tailwindlabs/tailwindcss/releases (الملف المناسب لجهازك)، وحطه مثلًا في `~/tailwindcss` واديله صلاحية تشغيل.

## 5) إزاي تبني وتنشر

```bash
# البناء (بيكتب الموقع كله في docs/)
TAILWIND_BIN=~/tailwindcss npx tsx scripts/build.tsx

# تشوفه على جهازك قبل النشر
npx serve docs
# افتح http://localhost:3000

# النشر
git add -A
git commit -m "وصف التعديل"
git push origin main
```
بعد الـ push بدقيقة-اتنين الموقع يتحدّث. لو شكله ماتغيرش: Cloudflare → Caching → **Purge Everything**.

## 6) إزاي تخلي ChatGPT (أو أي AI تاني) يكمّل

**الطريقة الأفضل:** استخدم أداة بتقدر تفتح الريبو وتعدل فيه مباشرة:
- **ChatGPT Codex** (chatgpt.com/codex): وصّله بحساب GitHub واختار ريبو `5aledelaraby/belts`.
- أو **Cursor** / **VS Code + Copilot** على الكمبيوتر بعد `git clone`.

**أول رسالة تبعتها للمساعد (انسخها زي ما هي):**
```
ده موقع متجر أحزمة اسمه Vicuna (vicuna-eg.com). اقرا ملف README.md كله الأول،
والتزم بقواعد البراند اللي فيه. الموقع React + TypeScript بيتبني لصفحات ثابتة
بأمر: TAILWIND_BIN=<مكان tailwind> npx tsx scripts/build.tsx
والناتج في docs/ ومنشور على GitHub Pages.
ماتعدلش في docs/ بإيدك. بعد أي تعديل اعمل build واتأكد إنه نجح، وورّيني قبل ما ترفع.
اتكلم معايا بالعامية المصرية.
```

**ChatGPT العادي (من غير وصول للكود):** ممكن تبعتله الملف اللي عايز تعدله (انسخه من GitHub) وتقوله التعديل، وهو يرجعلك الملف كامل، وتلزقه على GitHub بالقلم ✏️. بس لازم بعدها build (الخطوة 5).

**قواعد أمان:** ماتديش أي مساعد باسورد أو توكن (GitHub / Cloudflare / Meta). الأدوات زي Codex بتتوصل بزرار "Connect GitHub" من غير ما تكتب باسورد.

## 8) هيكل المشروع

```
src/
  data/        إعدادات المتجر، المنتجات، الأسئلة، كلام SEO
  components/  مكوّنات الصفحات (Layout, Sections, ProductPage, Blog, Icons, Illus…)
  content/     السياسات + المقالات (blog/*.md)
  client/      كود المتصفح: السلة، الخصم، واتساب، الأصوات، المؤثرات
  styles/      app.css (Tailwind v4)
  assets/      الصور والفيديوهات والخطوط الأصلية
  vendor/      GSAP + Lenis (محفوظين محليًا)
  pages.tsx    قائمة كل الصفحات
  seo.ts       العناوين والوصف و Schema
  blog.ts      قراءة المقالات
scripts/build.tsx   البناء: صور WebP + CSS/JS + الصفحات + sitemap + كتالوج المنتجات
workers/capi/       Cloudflare Worker لـ Meta Conversions API
docs/               الناتج النهائي (متتعدلش يدوي)
```
